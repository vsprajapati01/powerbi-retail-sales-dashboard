# Retail Sales Dashboard — Sales & Profit Performance (Power BI)

**Learning project** — a retail sales & profit dashboard built in Power BI Desktop as hands-on practice while preparing for the PL-300 (Power BI Data Analyst) certification.

## What's in it
- **Model (star schema):** `Sales_Raw` fact table (orders, sales, profit, discounts, order status…) linked to `Customers`, `Products`, and `DateTable` dimension tables — 3 relationships, 17 DAX measures
- **Dashboard:** KPI cards (Total Sales, Total Profit, Profit Margin %, Total Orders, Average Order Value), order-status donut, sales trend by month, breakdowns by category, region, product, salesperson, and customer, with Month/Region/Category/Order-Status slicers

## Skills practiced
- Dimensional modeling: star schema, dimension vs fact tables, relationships
- DAX: 17 measures (totals, margins, distinct counts, ratios)
- Dashboard design: KPI cards, donut/line/bar visuals, slicers, dark theme layout
